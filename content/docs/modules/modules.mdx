# Expansion Modules

The **A0 base board** pushes all additional radio and cellular connectivity onto removable modules. It provides **two expansion slots — BUS1 and BUS2** — where modules can be plugged in and swapped depending on the deployment.

## Supported Modules

| Module                                              | Radio                       | Use Case                                            |
| --------------------------------------------------- | --------------------------- | --------------------------------------------------- |
| [SIM7080G](./sim7080g)                              | NB-IoT / LTE-M + GNSS       | Cellular uplink, asset tracking                     |
| [WMBUS](./wmbus)                                    | Wireless M-Bus (EN 13757-4) | Utility meter reading                               |
| [E07-400M10S](./e07-400m10s)                        | Sub-GHz 400 MHz, 10 dBm     | Private sensor networks, long-range low-power links |
| [MikroE Click boards™](#mikroe-click-compatibility) | Various                     | Off-the-shelf Click ecosystem                       |

## MikroE Click Compatibility

In addition to the in-house modules, the A0 expansion slots (BUS1/BUS2) use the **same footprint as [MikroElektronika Click boards](https://www.mikroe.com/)**. This means the entire MikroE **Click™ ecosystem** — hundreds of off-the-shelf add-on boards covering GSM/LTE, LoRa, RF, sensors, storage, and more — can be plugged directly into the A0 base board.

Click boards communicate over standard buses (UART, SPI, I2C) routed through the expansion slots, so firmware on the ESP32-C6 talks to them with ordinary peripherals and drivers.

This gives the A0 gateway three levels of expandability:

1. **In-house modules** — SIM7080G, WMBUS, and E07-400M10S, purpose-built for metering gateways.
2. **MikroE Click boards™** — the whole off-the-shelf ecosystem, thanks to the shared footprint.
3. **Custom boards** — any board designed to the same Click-compatible footprint.

## Module Details

### SIM7080G

A plug-in module based on the **SIMCom SIM7080G** providing **NB-IoT / LTE-M (Cat-M)** cellular connectivity plus **GNSS** positioning (GPS/GLONASS/BeiDou/Galileo). Controlled via AT commands from the ESP32-C6 over UART.

- Cellular uplink for NB-IoT and LTE-M deployments
- GNSS support for asset tracking
- Dedicated RF and GNSS antenna connectors
- BUS1 wiring: modem TX→GPIO16, RX→GPIO17 @115200 baud, PWRKEY→GPIO1, RING→GPIO3; GPIO14→DTR via U1 slide switch (must be set to MiBUS1 side)

### WMBUS

A **Wireless M-Bus (EN 13757-4)** module for reading utility meters (heat, water, gas, electricity), built around the **Radiocontrolli RC-S2LP-868** (ST S2-LP, 868 MHz). Connects to the ESP32-C6 over SPI on BUS1/BUS2 and is powered from the slot (+3V3).

- BUS1 SPI: SCK GPIO20 / MISO GPIO19 / MOSI GPIO18, CS GPIO2, SDN GPIO1
- Bring-up: [Wireless M-Bus Testing](../tests/wireless-mbus) — PARTNUM `0x03` check confirms the link

### E07-400M10S

A module based on the **EBYTE E07-400M10S** (TI CC1101, LCSC `C2965513`) sub-GHz (400 MHz, 10 dBm output) RF transceiver — suited to low-power, long-range private sensor networks.

- BUS1 SPI: same SCK/MISO/MOSI/CS as WMBUS; GDO0→GPIO1, GDO1→GPIO0 — modules are slot-interchangeable
- Bring-up: [E07-400M10S Sub-GHz](../tests/e07-400m10s) — PARTNUM `0x00` / VERSION `0x14` / MARCSTATE `IDLE` checks
