**Abstract Machines Hardware** provides modular, open-source IoT gateway solutions designed for smart metering, industrial automation, and edge computing applications. Our hardware platform combines the **A0** (ESP32-C6 module carrier) with plug-in **expansion modules** to deliver flexible, scalable, and professional-grade connectivity.

## Products

### A0 IoT Gateway

Swiss knife for wireless IoT. The A0 is powered by ESP32-C6 RISC-V (Wi-Fi 6, Bluetooth 5 LE, 802.15.4 for Thread/Zigbee) with secure boot, flash encryption and TEE. It runs Zephyr RTOS. Radio/cellular connectivity is added via plug-in expansion modules on the A0 BUS1/BUS2 slots — SIM7080G (NB-IoT/LTE-M + GNSS), WMBUS (Wireless M-Bus metering), and sub-GHz E07-400M10S (400 MHz).

## Key Features

- **Multi-Protocol Support**: Wireless M-Bus, NB-IoT, LTE-M, Wi-Fi 6, BLE 5, and 802.15.4 (Thread/Zigbee), plus sub-GHz
- **Low Power**: Ultra-low power design with USB-C, external supply, and battery with charging support
- **Modular Design**: A0 Base Board with 2 expansion slots (BUS1/BUS2) for plug-in radio/cellular modules
- **Open Source**: Apache 2.0 license with full documentation
- **Professional Support**: Commercial support from Abstract Machines
